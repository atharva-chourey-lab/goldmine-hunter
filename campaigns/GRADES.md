# Goldmine Hunter — grades (fixed 2026-11-18, BEFORE Campaign 6 / Wave 1)

Written and git-committed before Campaign 6 ran, at Atharva's
direction, so no find can be graded against a definition invented
after it was seen. These definitions govern this and future waves.
Changing a definition requires its own commit, with the reason,
and never retroactively upgrades a graded find.

## The grades

- **GOLD** — a sample-verified STRANDED or DELETED comparable set:
  the same derived data type across many comparable units, absent
  from the formal archive, with (a) an identifiable un-run
  comparison it enables AND (b) a local anchor / ground truth to
  grade that comparison against. **All elements required** —
  stranded/deleted provenance, comparable set, un-run comparison,
  anchor. Missing any one, it is not gold.

- **DIAMOND** — GOLD, plus a headline-class result already visible
  in the verified set itself: two rulers measurably disagreeing, a
  canon demonstrably photocopied/derived rather than measured, a
  comparison nobody can have run because the set was unrecoverable
  — something that, if the comparison lands, overturns or reveals,
  not merely adds. A diamond must be visible in the set, not hoped
  for from the comparison.

- **SILVER** — verified vintage / comparison material on
  published-by-design data (the CRU class: kept version stacks,
  openly served historical ledgers, curated archives). Real and
  analysis-ready, but a recovery of nothing.

- **INVENTORY** — verified real data files, published by design,
  that complete no comparison and form no vintage stack of note.
  Counted, never dressed up.

- **KILL** — a probed target that yields nothing claimable:
  phantoms (HTML served as data), data behind an interface with no
  file pile (adapter class, stated as such), unreachable hosts,
  consolidated/published flagships where the niche was aimed at
  strays. Named plainly, with the evidence.

## Evidence rule (no exceptions)

No grade is awarded on raw counts. Every GOLD / DIAMOND / SILVER
claim needs ≥1 sample download per set with size + md5 +
magic/header recorded in the wave's verify output. Wayback piles
are counted only after statuscode:200 filtering. A set whose
samples turn out to be HTML phantoms is a KILL, however large the
raw count.

## Provenance classes (unchanged, from the analysis-first doctrine)

STRANDED (on the project site, absent from the formal archive) /
DELETED (Wayback or old versions only) / PUBLISHED-BY-DESIGN /
PHANTOM. Grade and provenance are reported separately and never
blurred: a DELETED set can still fail GOLD (no anchor, no un-run
comparison), and a PUBLISHED stack is at most SILVER.
