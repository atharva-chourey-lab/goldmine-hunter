# Spin-off: Manatee Scar Sheets — RUN (pre-registered fallback: coverage audit)

Minted from Goldmine Hunter **Campaign 8 / Mammal Wave 2** (2026-11-18;
`campaigns/SHORTLIST-CAMPAIGN8-MAMMAL2-2026-11-18.md`), which graded
Wayne Hartley's hand-drawn Blue Spring scar-sheet catalogue (frozen
April 2013, stranded on Save the Manatee Club's archive subdomain,
absent from the formal photographic MIPS system) as **GOLD**.

The pre-registered audit has now been **run**: the complete frozen set
was transcribed (210 entries, 209 with catalogue IDs) and joined to
every public post-2013 record sourced. The public ruler joined only
**45 of 209 (21.5%)**, so the pre-registered fallback governs: the
deliverable is a **coverage audit and non-representative case series**,
scorecard 2 pass / 3 fail / 1 void — published separately as the lab's
`manatee-scar-sheets` manuscript repository (CC BY 4.0, not yet
peer-reviewed). Within the joined subset, identities persisted far
past the sheet's own drop rules (median last record 2025); the silent
majority is untested, and the prepared MIPS data request is the main
forward path. Contents: `MANUSCRIPT.md`, `RESULTS.md`,
`transcription.csv`, `ruler.csv`, `TRANSCRIPTION-METHODS.md`,
`NOVELTY.md`, `PREREGISTRATION.md`. The source PDFs are not
redistributed (see `campaigns/SAMPLES-MANIFEST.md`).
